🎲 Referee's Screen

Every rule both games actually run on, laid out in panels. Written down partly so the games stay consistent as they grow, and partly because a screen was always the accessory that made these things playable at a table.

Both games use original mechanics — nothing here is reproduced from any published rulebook.
Kellath's Drift rolls percentile and wants to roll low. Offline Protocol rolls an ascending die ladder and wants to roll high.
This page prints cleanly if you want it on paper.

🚀 Kellath's Drift — percentile
Play →

The Core Roll

Roll 2d10 — one die is tens, one is ones.
A read of 00 counts as 100.

Success if the roll is ≤ your target.

Lower is better. The target number is built from an ability score, then adjusted by specialization and gear.

Building a Target Number

Target = ½ ability score
  + 15 if your PSA covers it
  + 10 if relevant gear in hand
  (minimum 5)

A few checks use the full ability score instead of half — those are the ones the story frames as brute-force rather than finesse.

The Core Roll

Roll the subsystem's die,
add its modifier,
meet or beat the DC.

Higher is better. Bigger dice mean wider swings — the combat processor can roll brilliantly or catastrophically, the social subroutines mostly land in the middle.
